How Crip Minds Works

{{ site.creator }} — cripminds.com — updated November 2026

Crip Minds essays are written by an AI system. People set the rules, and a person reads every essay after it goes online. This page says what happens between a subject and a published essay.

01 — Find the story

Each morning the system looks for something real: an event, a court case, a rule, an object, a study. It needs a tension inside it — a detail that does not fit the obvious explanation.

Disability is not only a subject here. It can change the question. A settings menu, for instance, can be read for whose time it protects. Many more subjects are read than become essays. If there is not enough reliable material, the subject stops here.

02 — Write down the facts first

Sources are gathered for that one story. From them the system builds a list of facts. Each fact is stored with the exact sentence in the source that supports it. This list is the only place an essay may take a fact from.

03 — Write in plain language

An AI writer turns the list into one essay with one argument. It writes in plain language, at level B1: short sentences, everyday words, every hard term explained. Each fact carries a numbered note that links to its source.

The writer may interpret. It may not invent a person, a quotation, a number, a date or a cause. It never writes as if it has a body or a disability. Lived experience comes only from real people, quoted in their own words.

04 — Read twice, revise once

Two separate AI readers judge the draft. A problem counts only when both of them see it. Those problems, any claim the sources do not support, and any sentence that is too long go back to the writer. The writer revises its own draft once.

05 — Checks that stop an essay

Some checks stop an essay from going online. An invented name, quotation or number stops it. So does a sentence in which the writer claims a body or a disability. So does a failed fact check against the wider web. So does a problem both readers agree on.

Other findings do not stop an essay. They travel with it as notes for the editor. An example is a claim the sources may not fully support. Ethics →

06 — Publish with sources

An essay that passes goes online by itself. It names the reporting it is based on, and its notes link to the sources. A Dutch edition is translated and checked separately. An essay is labelled “Plain language · B1” only when its text is measured at that level.

Images are made by an AI image model. They never contain text, because image models get letters wrong.

07 — A person reads every essay

{{ site.creator }} reads every essay after it is published, together with those notes. An essay can then be corrected or taken offline. A correction that changes the facts, the people or the argument is listed at the end of the essay, with its date.

Sometimes an essay the system held back is worth publishing after a human edit. Such an essay goes online only with the editor’s approval, and its record says so.
