Curated routes through recurring subjects.

{% comment %} WHAT GETS PROMOTED, AND WHY. A "collection" that currently carries one essay is not yet a route through a subject, and one whose members have all been archived is not a current recommendation at all. Giving either the same prominence as a nine-essay collection told the reader something untrue about the shape of the archive. So the primary list below is collections carrying TWO OR MORE currently-carried essays. Everything else stays reachable, correctly labelled, in a quiet line underneath -- nothing is deleted, no membership changes, and a grouping that grows to two carried essays appears in the main list automatically. Counts are of carried essays only, so an archived member is never presented as current.
