## 1. WHY THIS CAN BE WRITTEN NOW, BEFORE CJ-2 PRODUCES A REAL WINNER

Phase G's bridge (`cj2_winner_bridge.build_bridge_payload`) already defines the
shape a CJ-2 winner takes once bridged — `cj2_shadow_integration_test.py` proves
byte-identical prompts between OFF and SHADOW modes today, meaning the ONLY
thing this pilot would ever change is which winner (if any) seeds the brief, not
any other part of generation. That's exactly the controlled variable a paired
comparison needs, and it's real, tested code today — the pilot's contract can be
written against it without waiting for a live winner to exist.

## 2. PAIRED ARTIFACT CONTRACT

Never compare unrelated topics and call it evidence. A pilot pair is:

- **LEGACY_ARTICLE** — a real, normally-published article, generated by the
  live pipeline with `CJ2_INTEGRATION_MODE=OFF` (today's default and the only
  mode that has ever actually published anything).
- **CJ2_WINNER_SOURCED_ARTICLE** — a draft generated from the SAME run context
  as LEGACY_ARTICLE, except the fable_brief's seed is sourced from a real CJ-2
  winner instead of the normal news_seed/discovery path.

Both members of a pair MUST share, verified before either is evaluated:
- the same topic (same underlying news_seed/discovery finding)
- the same `evidence_packet` (identical `source_hash`/`evidence_packet_hash` —
  the exact invariant `generate.py` already enforces for a single run, extended
  here to mean "both members of a pair were built from one evidence_packet, not
  two separately-fetched ones")
- the same source snapshot (whatever `fetch_source_article` returned at the time
  the pair was generated — not re-fetched independently for each member, which
  would let source drift confound the comparison)
- the same production date / run context (persona pool, register pool, length
  pool draws may differ per member since they're independent random draws, but
  the SEED material — topic, evidence — does not)
- a comparable article_type/format between members (an essay legacy vs. a
  field_note CJ2-sourced draft is not a valid pair)
- explicit, recorded path provenance for each member — reusing `cj2_shadow.py`'s
  own `PATH_LIVE_LEGACY`/`PATH_CJ2_WINNER_DRAFT` constants (the second already
  named, defined, and marked "not reachable this pass" — this protocol is what
  would make it reachable, later, not now)

A pair with mismatched evidence_packet hashes is not a pair — it's two unrelated
articles that happen to share a topic label, and any comparison built on it is
void by construction, not merely weak evidence.

## 3. ARTICLE-LEVEL DIMENSIONS (preregistered, not run)

Three tiers, kept separate rather than collapsed into one score, because they
need different kinds of evidence and different confidence:

### DETERMINISTIC (code, zero model calls — run identically on both members)
- Word count vs. article_type contract (`_check_length_adherence_shadow`, item E)
- Readability (`_readability_score`, existing FRE≥55 gate)
- Buried-clause / argument-word / sentence-length-distribution checks (existing
  `gate.py` deterministic checks)
- Repetition-shadow candidate count (`_check_repetition_shadow`, item G)
- Internal-labels-absent: a deterministic grep for CJ-2/Stage-C internal
  vocabulary ("Stage C", "admission gate", "engine_move", "conceptual_shift",
  persona-internal jargon) that must never leak into published prose — this is
  the one NEW deterministic check this protocol would need that doesn't exist
  yet; a simple substring/regex scan, same shape as `_check_forbidden_word_lists_shadow`.

### MODEL/JUDGE (an LLM evaluates one article, or the pair, against a rubric)
- **Winning insight preserved** — does the article's actual angle/thesis match
  what CJ-2's winner claimed to contribute, or did drafting quietly substitute a
  safer, more generic angle? Needs the winner's `claimed_contribution`/
  `engine_move` (already in the bridge payload, per `cj2_winner_bridge_test.py`)
  as the comparison target — a judge reads the payload's claim and the article,
  answers PRESERVED / DILUTED / LOST.
- **Disability lens reveals mechanism, not just topic** — per item K's doctrine
  ("a way of perceiving that reveals something the dominant world has failed to
  notice," not "disability as the default topic"), a judge checks the CJ2-sourced
  article didn't collapse into disability-as-subject when the winner's actual
  contribution was a mechanism visible FROM a disability perspective on a
  non-disability topic.
- **Factual grounding / no new drafting hallucination** — reuses the EXISTING
  `_reject_if_unsupported_specifics`/`validate_evidence_field` machinery
  unchanged; a CJ2-sourced draft gets no special exemption from grounding checks
  a legacy draft already has to pass.
- **Category jump / contribution** — does the finished article actually deliver
  a genuinely different observation than a legacy article on the same topic
  would have, or is the "jump" CJ-2 selected for invisible by the time the piece
  is written? Comparative judge call, LEGACY_ARTICLE vs CJ2_WINNER_SOURCED_ARTICLE
  side by side.
- **Progression / repetition** (folds in reconciliation item D — "correction
  discipline" is the same underlying question: does the article's structure
  actually develop an idea, or restate it) — informed by, not replacing, the
  deterministic repetition-shadow signal above.
- **Correction integrity** — where the article corrects an assumption or
  complicates its own opening claim (a named structural device in this
  publication's house style), does that correction land, or does CJ-2-sourced
  material make it feel grafted-on rather than earned?
- **Public-language quality / editorial publishability** — a holistic "would this
  ship as-is" judge call, distinct from the deterministic gate.py checks (which
  catch specific known failure patterns, not overall quality) — same spirit as
  `_engagement_read`, reused as a rubric dimension here rather than a new
  mechanism.

### HUMAN CALIBRATION (Reader Lab or direct editorial read)
- All of the above MODEL/JUDGE dimensions, re-checked by a human on a sample —
  same discipline the B2/CJ-2 freeze protocol already uses for its own
  human-calibration gate, not a new methodology invented for articles.
- A human-only question no judge rubric above can answer: **does the finished
  piece actually feel different in a way a reader would notice**, or is any
  measured improvement an artifact of the evaluation rubric rather than the
  reading experience?

## 4. STOP RULE — WHAT COUNTS AS ENOUGH

No large sample size is invented here. Following the freeze protocol's own
precedent (structural gates + paired evidence over raw N):

**CJ-2 INTEGRATION IMPROVES / PRESERVES ARTICLE QUALITY** is supported when, across
a small number of valid pairs (contract in `## 2` satisfied for every pair — an
invalid pair doesn't count toward the total either way):
- Zero DETERMINISTIC regressions (a CJ2_WINNER_SOURCED_ARTICLE that fails a check
  its LEGACY_ARTICLE pair passes, on the same evidence_packet, is a structural
  failure, not a judgment call — one such regression is enough to fail this
  criterion, no averaging).
- MODEL/JUDGE "winning insight preserved" scores PRESERVED (not DILUTED/LOST) on
  a clear majority of pairs.
- HUMAN CALIBRATION agrees with the MODEL/JUDGE tier's direction (improved/
  preserved/worse) on a clear majority of the sampled pairs — disagreement here
  means the judge rubric itself needs recalibration before the result can be
  trusted, not that the pilot failed.

**CJ-2 IDEA QUALITY DOES NOT SURVIVE DRAFTING** is supported when "winning insight
preserved" scores DILUTED/LOST on a clear majority of pairs, REGARDLESS of
deterministic/readability scores — a fluent, clean, publishable article that lost
the actual reason CJ-2 selected it is exactly the failure mode this pilot exists
to catch, and passing every mechanical check does not offset it.

Anything in between (mixed results, small pair count, disagreement between
judge and human tiers with no clear direction) is preregistered here as
**INCONCLUSIVE — more pairs needed**, not rounded to either answer. This mirrors
the freeze protocol's own refusal to force a premature yes/no from Shape C's
missing evidence.
